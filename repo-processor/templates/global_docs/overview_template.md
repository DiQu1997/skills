OVERVIEW.md format rules:

Required headings:
- Top-level heading: Project name followed by "— AI Agent Overview"
- ## Purpose
- ## Tech Stack
- ## Build & Run
- ## Design Philosophy
- ## Project Structure

Content requirements:
- Purpose: 3-5 sentences.
- Tech Stack: table with columns Component, Technology, Version, Notes.
- Build & Run: include build, test, and run commands.
- Design Philosophy: 3-5 bullet points.
- Project Structure: tree view with directory purposes.

Global rules:
- Output Markdown only.
- No placeholders or ellipses in the final document.
- If a section has no content, write "None" on a single line.
