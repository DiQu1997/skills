QUICK_REFERENCE.md format rules:

Required headings:
- # Quick Reference
- ## Key Types
- ## Key Functions
- ## File → Responsibility Map
- ## Glossary

Content requirements:
- Key Types: table with Type, Module, One-liner.
- Key Functions: table with Function, Signature, One-liner.
- File → Responsibility Map: table with File, What It Does.
- Glossary: table with Term, Meaning.

Global rules:
- Output Markdown only.
- No placeholders or ellipses in the final document.
- If a section has no content, write "None" on a single line.
