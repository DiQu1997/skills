CONVENTIONS.md format rules:

Required headings:
- # Coding Conventions
- ## Naming
- ## Error Handling
- ## Testing
- ## Logging
- ## Code Style

Content requirements:
- Naming: types, functions, constants, file naming.
- Error Handling: return types, error enums, propagation rules.
- Testing: unit/integration locations and naming rules.
- Logging: framework and level usage.
- Code Style: max line length, import order, and other style rules.

Global rules:
- Output Markdown only.
- No placeholders or ellipses in the final document.
- If a section has no content, write "None" on a single line.
