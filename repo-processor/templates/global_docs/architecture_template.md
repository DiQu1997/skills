ARCHITECTURE.md format rules:

Required headings:
- # Architecture
- ## System Diagram
- ## Module Dependency Graph
- ## Key Data Flows
- ## Layer Rules

Content requirements:
- System Diagram: Mermaid or ASCII.
- Module Dependency Graph: directed graph.
- Key Data Flows: 3-5 flows, each with entry point and numbered steps.
- Layer Rules: list of allowed and disallowed dependencies.

Global rules:
- Output Markdown only.
- No placeholders or ellipses in the final document.
- If a section has no content, write "None" on a single line.
